🧮 Smart Calculator Web App

A simple, responsive, and interactive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic calculations with a clean user interface and easy-to-use buttons.

✨ Features

- ➕ Addition, subtraction, multiplication, and division
- 🔢 Supports decimal and negative numbers
- 📊 Percentage calculation
- 🧹 Clear all input using the AC button
- ⌫ Delete the last digit using the DEL button
- ➖ Toggle between positive and negative numbers
- 📝 Displays the mathematical expression and result
- ⌨️ Supports keyboard input
- ⚠️ Handles invalid calculations, including division by zero
- 🎨 Clean and user-friendly interface

🛠️ Technologies Used

- HTML5 – Structures the calculator and its buttons.
- CSS3 – Styles the calculator layout, buttons, colours, and display.
- JavaScript – Handles calculations, button interactions, and keyboard controls.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Make sure all three files ("index.html", "style.css", and "script.js") are in the same folder.
4. Open "index.html" in your web browser.
5. Start performing calculations!

No additional libraries or installations are required.

⌨️ Keyboard Shortcuts
